# Калькулятор отопления в Сербии

Интерактивный калькулятор для сравнения вариантов отопления частного дома в Сербии.

## Возможности

- **5 вариантов отопления**:
  - Газовый котёл
  - Дровяной котёл
  - Тепловой насос
  - Климатические системы по комнатам
  - Пеллетный котёл

- **Расчёт включает**:
  - Теплопотери дома (площадь + уровень утепления)
  - Капитальные затраты на монтаж
  - Годовые расходы на топливо/электричество
  - Обслуживание и ремонт
  - Распределение электроэнергии по тарифным зонам (зелёная / синяя / красная)
  - Двухтарифный счётчик (опция)

- **Сравнение**:
  - Таблица по стоимости на 1, 5 и 10 лет
  - Выделение наиболее выгодного варианта
  - Пояснения к каждому варианту

## Как использовать

1. Откройте `index.html` в браузере или перейдите на GitHub Pages
2. Введите параметры вашего дома (площадь, утепление, климат)
3. Установите актуальные цены на топливо и электроэнергию
4. Смотрите сравнение затрат
5. Нажмите "Сбросить средние значения" чтобы вернуться к дефолтам

## Структура файлов

- `index.html` — форма и разметка
- `styles.css` — стили (Bootstrap + кастомные)
- `script.js` — расчётная логика и обновление UI

## Дефолтные значения для Сербии

- Площадь: 180 м²
- Уровень утепления: среднее
- Теплопотери: 75 кВт·ч/м²/год
- Период отопления: 6 месяцев
- Газ: 0,95 €/м³
- Дрова: 85 €/м³
- Пеллеты: 230 €/т
- Электроэнергия: 0,07–0,17 €/кВт·ч по зонам

Все значения можно менять в любой момент.

## Техническая информация

- Без зависимостей (кроме Bootstrap CDN для стилей)
- Полностью клиентский расчёт (JS в браузере)
- Подходит для хостинга на GitHub Pages
